<h1 align="center">💸 Payments App</h1>

<p align="center">
  A full-stack <strong>digital payments application</strong> that allows users to manage wallets, transfer money, and track transactions — securely and in real-time.
  <br>
  <em>Inspired by Paytm, Venmo, and Cash App.</em>
</p>

<h2>🚀 Features</h2>

<ul>
  <li>🔐 User Registration & Secure JWT Login</li>
  <li>💰 Digital Wallet with Balance Management</li>
  <li>🔄 Send and Receive Payments Instantly</li>
  <li>📜 View Transaction History</li>
  <li>📱 Fully Responsive (Mobile-First)</li>
  <li>📦 Modular Codebase (Frontend + Backend)</li>
</ul>

<hr>

<h2>🛠️ Tech Stack</h2>

<h3>Frontend</h3>
<ul>
  <li><strong>React.js</strong> – Component-based UI</li>
  <li><strong>Tailwind CSS</strong> – Utility-first styling</li>
  <li><strong>React Router</strong> – SPA Routing</li>
  <li><strong>Axios</strong> – API Integration</li>
</ul>

<h3>Backend</h3>
<ul>
  <li><strong>Node.js</strong> – JavaScript runtime</li>
  <li><strong>Express.js</strong> – RESTful APIs</li>
  <li><strong>MongoDB + Mongoose</strong> – Database & ODM</li>
  <li><strong>JWT</strong> – Authentication</li>
</ul>

<h2>📦 Getting Started</h2>

<details>
  <summary><strong>📁 Clone the Repository</strong></summary>
  <pre><code>git clone https://github.com/yourusername/payments-app.git
cd payments-app</code></pre>
</details>

<details>
  <summary><strong>📥 Install Dependencies</strong></summary>

  <p><strong>Frontend:</strong></p>
  <pre><code>cd client
npm install</code></pre>

  <p><strong>Backend:</strong></p>
  <pre><code>cd server
npm install</code></pre>
</details>

<details>
  <summary><strong>⚙️ Setup Environment Variables</strong></summary>

  <p>Create a <code>.env</code> file in the <code>server/</code> directory:</p>
  <pre><code>PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key</code></pre>
</details>

<details>
  <summary><strong>🚀 Run the Application</strong></summary>

  <p><strong>Start Backend:</strong></p>
  <pre><code>cd server
npm run dev</code></pre>

  <p><strong>Start Frontend:</strong></p>
  <pre><code>cd client
npm start</code></pre>
</details>
